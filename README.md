# DH Coding — ศูนย์การเรียนรู้การเขียนโปรแกรม

เว็บไซต์เรียนเขียนโปรแกรมสำหรับผู้เริ่มต้น ภาษาไทย

- **6 คอร์ส:** Python, Java, C, C++, HTML และ CSS รวม 50 บท พร้อมบทนำทุกบท
- **แบบฝึกเขียนโค้ด 230 ข้อ** ตรวจคำตอบอัตโนมัติ และมีคำใบ้ทีละระดับ
- **Quiz** ภาษาละ 3 ระดับ ระดับละ 30 ข้อ สุ่มคำถามและตัวเลือกทุกครั้ง
- **Minigame** สำหรับพักสมอง
- ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (HTML, CSS และ JavaScript อยู่ในไฟล์เดียว) |
| `code-cats-world.webp` | ภาพพื้นหลังหน้าแรก |
| `java-cat.png` | รูปตัวอย่างที่ใช้ในโจทย์ HTML เรื่อง `<img>` |

## วิธีนำไปติดตั้ง (สำหรับผู้ดูแลเว็บ)

เป็นเว็บแบบ static ไม่ต้องใช้ฐานข้อมูล ไม่ต้องใช้ PHP หรือ Node.js

1. ดาวน์โหลดไฟล์ทั้ง 3 ไฟล์ (ปุ่ม **Code → Download ZIP**)
2. อัปโหลดไว้ในโฟลเดอร์เดียวกันบนเซิร์ฟเวอร์ เช่น `/learn/`
3. เปิดที่อยู่ของโฟลเดอร์นั้น เช่น `https://เว็บสาขา/learn/` ได้ทันที
4. ใส่เมนูหรือลิงก์ "ศูนย์การเรียนรู้" ในเว็บหลักให้ชี้มาที่โฟลเดอร์นี้

ไฟล์อ้างอิงกันแบบ relative path จึงวางในโฟลเดอร์ชื่ออะไรก็ได้ ขอแค่ให้ทั้ง 3 ไฟล์อยู่ด้วยกัน

## หมายเหตุ

- ความคืบหน้าของผู้เรียนเก็บไว้ในเบราว์เซอร์ของผู้เรียน (localStorage) ไม่มีระบบสมาชิก
- ผู้ใช้ต้องต่ออินเทอร์เน็ต เพราะฟอนต์โหลดจาก Google Fonts
- ไม่แนะนำให้ฝังด้วย `<iframe>` จากโดเมนอื่น เพราะบน Safari ความคืบหน้าของผู้เรียนอาจไม่ถูกบันทึก
